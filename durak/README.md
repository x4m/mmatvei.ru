# Дурак

Сетевая игра в подкидного дурака для 2–4 игроков.

- `/durak/` — личный пульт: свои карты, весь стол и все действия. Подходит
  телефону или планшету и не требует видеть телевизор.
- `/durak/?tv` — общий крупный экран без карт игроков.
- Партия стартует автоматически, когда подключены минимум два игрока и каждый
  нажал «Я готов».
- Колода — 54 карты: от двоек до тузов и два джокера. Любой джокер бьёт любую
  карту, в том числе другого джокера.

Локальный запуск:

```bash
npm install
npm start
```

После этого открыть `http://localhost:8082`.
