# NEON LABYRINTH — 3D-шутер в лабиринте

Мультиплеерный шутер от первого лица. Карта — та же неоновая арена, что и в `test/`,
но внутри достроен лабиринт из стен в том же стиле (сотовая решётка, бирюзовый неон,
розовый периметр, звёздное небо).

## Запуск (нужен Node.js 16+)

```bash
npm install
node server.js
```

Открой в браузере **http://localhost:8080** — клиент раздаётся самим сервером.

## Правила

- В бою **5 слотов**. Если живых игроков меньше — свободные места занимают **боты**.
- У каждого **100 HP**. Попадание в корпус — 20, в голову — 45.
- **Каждые 3 фрага — полное восстановление здоровья.**

## Оружие

| | Винтовка | Гранатомёт |
|---|---|---|
| Урон | 20 корпус / 45 голова | до 85 по площади, радиус 6.5 м |
| Магазин | 30 | 4 |
| Темп | 10 выстр./с, автомат | 1 выстрел / 0.75 с |
| Перезарядка | 1.9 с | 2.6 с |

Граната летит по дуге (34 м/с, гравитация 22) и рвётся от любого касания.
**Своя граната ранит** — на близкой дистанции получаешь 45% урона, так что вблизи не мажь.
Стены и вышки закрывают от взрыва: сервер проверяет линию до каждого бойца.

### Rocket jump

Взрыв отбрасывает — этим и пользуются. Прыжок плюс выстрел себе под ноги поднимает
примерно на **5.2 м** ценой ~33 HP. Ровно столько нужно, чтобы попасть на мачту вышки.

## Вышки

На карте 4 вышки, каждая в открытой клетке-площадке:

- **нижний ярус** (4.4 × 4.4 м, высота 1.2 м) — запрыгиваешь с земли обычным прыжком;
- **мачта** (2 × 2 м, высота 4.5 м) — **только rocket jump-ом**.

Вокруг мачты на нижнем ярусе есть кольцевая площадка, по ней можно обойти вышку кругом.
Клетка с вышкой всегда лишена стен — иначе основание затыкало бы проход и разрезало лабиринт.
- Матч длится **5 минут**, побеждает боец с наибольшим числом фрагов. Между боями перерыв 12 секунд.
- Возрождение через 3 секунды в точке, максимально удалённой от живых противников.
- **Лабиринт генерируется заново на каждый матч** — карта каждый раз новая.
- Вид **только от первого лица**.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `W` `A` `S` `D` |
| Обзор | Мышь |
| Огонь | ЛКМ |
| Прицеливание | ПКМ |
| Смена оружия | `1` / `2` / `Q` / колесо мыши |
| Бег | `Shift` |
| Прыжок | `Пробел` |
| Перезарядка | `R` |
| Таблица счёта | `Tab` |
| Пауза / настройки | `Esc` |

На телефоне: левый джойстик — движение, свайп справа — обзор, кнопки «ОГОНЬ», «↑», «R».

## Настройки

В меню и в паузе (`Esc`):

- **Чувствительность мыши**
- **FOV** (поле зрения, 60–120°)
- **FOV при прицеливании**
- **Чувствительность в прицеле**
- **Покачивание камеры при ходьбе** (0–100%, на нуле выключено)

Настройки сохраняются в `localStorage`.

## Выбор сервера

В меню — список серверов по протоколу **WebSocket**. Каждый пингуется через `GET /status`
и показывает, сколько живых игроков онлайн. Свой адрес добавляется в поле снизу
(`ws://адрес:8080` или `wss://...` для HTTPS), список хранится в браузере.

### Свой сервер

- **Локальная сеть:** друзья открывают `http://<твой-IP>:8080` (узнать IP: `ipconfig`).
- **Интернет:** деплой на любой Node-хостинг (Render, Railway, Fly.io, VPS) — порт берётся
  из `process.env.PORT`, имя сервера — из `process.env.SERVER_NAME`.

Переменные окружения: `PORT`, `SERVER_NAME`, `MATCH_SEC` (длительность боя, по умолчанию 300),
`BREAK_SEC` (перерыв, 12), `LOBBY_SEC` (ожидание игроков перед добором ботов, 15).

Если игроков больше пяти, сервер автоматически поднимает вторую комнату со своим лабиринтом.

## Файлы

- `server.js` — WebSocket-сервер: генерация лабиринта, комнаты, боты, хитскан-попадания, счёт
- `client.html` — клиент на Three.js: рендер, процедурные текстуры, FPS-управление, HUD
- `test/` — исходный пример (SNAKE.IO 3D), откуда взяты карта и стиль

## Протокол (кратко)

Клиент → сервер: `join`, `state` (20 Гц), `shoot` (направление луча), `ping`
Сервер → клиент: `welcome` (конфиг + лабиринт), `snap` (20 Гц), `shot`, `hit`/`hurt`/`hp`,
`kill`, `spawn`, `scores`, `lobby`, `matchStart`, `matchEnd`, `pjoin`/`pleave`, `pong`

Попадания считает сервер (трассировка луча по стенам и цилиндрам бойцов) — клиент рисует
только эффекты.
