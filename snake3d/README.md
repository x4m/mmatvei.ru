# SNAKE.IO 3D — Online Arena

3D-мультиплеер от первого лица: 5-минутные соревновательные матчи, профили игроков и эксклюзивные скины за победы.

## Запуск (нужен Node.js 16+)

```bash
npm install
node server.js
```

Затем открой в браузере: **http://localhost:8080** — клиент раздаётся самим сервером.

## Игра по сети с друзьями

- **Локальная сеть:** друзья открывают `http://<твой-IP>:8080` (узнать IP: `ipconfig` / `ifconfig`).
- **Интернет:** задеплой на любой Node-хостинг (Render, Railway, Fly.io, VPS) — порт берётся из `process.env.PORT`. В поле «Сервер» в меню игры можно ввести адрес вручную (`ws://...` или `wss://...` для HTTPS).

## Механика

- **Матч длится 5 минут.** Побеждает игрок с наибольшим счётом. Между матчами перерыв 15 секунд, потом всё обнуляется.
- **Очки:** еда +10, большая сфера +40, убийство игрока +50. Смерть в матче — минус половина очков.
- **Скины за победы:** Золото — 1 победа, Плазма — 3, Галактика — 5, Дракон — 10. Привязаны к имени и сохраняются на сервере в `data.json`.
- Убить соперника: заставь его врезаться в твоё тело. Его останки рассыпаются в еду.

## Управление

Мышь / A / D — поворот · ЛКМ / Shift / кнопка ⚡ — ускорение (тратит длину) · V или кнопка — вид от 1-го/3-го лица. На телефоне: свайп — руль, второй палец или ⚡ — буст.

## Файлы

- `server.js` — WebSocket-сервер: матчи, еда, счёт, профили, скины
- `client.html` — клиент (Three.js, процедурные текстуры)
- `data.json` — создаётся автоматически, база профилей
